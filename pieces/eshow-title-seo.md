## Revisión de voz

Canal: web / blog. Kill list sobre las opciones de title. Un title es corto por oficio; no se marca fallo por eso.

| Fallo buscado | ¿Estaba? | Corrección |
|---|---|---|
| Em dash | No | — |
| Dos puntos como pegamento de oraciones | El actual y las opciones 1 y 2 usan «:» entre el nombre y el dato | En un title eso es etiqueta, no dos oraciones pegadas. Se deja. |
| Staccato de tres palabras | No | Cada base nombra el evento y un dato. |
| José falso | No | No hay «yo». |
| Contraste binario / carraspeo / falsa revelación | No | — |
| Grandilocuencia | «imprescindible», «lo que nadie te cuenta» | No están. |
| Metáfora | No | Fechas, IFEMA, guía, cobertura. |
| Futuro simple | No | — |
| Rotar el nombre del evento | Tentación E-SHOW / eShow / feria | En este post se deja «eShow Madrid 2026», que es el nombre live y el de la URL. |
| Cifras sin fuente | No | — |
| Promesa inventada | Informe, resumen diario, avisos | Fuera del title. Están en el cuerpo del post y no son este encargo. |
