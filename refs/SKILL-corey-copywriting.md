# Copywriting (extracto aplicado a esta pieza)

Pieza de web → `copywriting`. Claridad antes que ingenio. Específico antes que vago. Una idea por bloque. El buyer vive en el brief, no en el texto. En este encargo no hay CTA de venta.

## Before Writing (aplicado)

1. Page purpose: formulario web para dejar el correo y recibir avisos/notas de José sobre el E-SHOW.
2. Audience (brief, no se imprime): dueños de e-commerce que ya venden.
3. Offer: avisos/notas de José Reyes desde la feria. No es diagnóstico, no es reunión, no es stand ni charla.
4. Context: José asiste como visitante. La página `/avisos-eshow` aún no está en vivo (404 el 14 oct 2026).

## Principles used

- Clarity over cleverness
- Specificity over vagueness
- One idea per section
- Honest over sensational
- Direct: value in the first line, not buried
